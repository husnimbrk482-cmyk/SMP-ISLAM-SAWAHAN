# Website SMP ISLAM SAWAHAN

Website satu halaman yang responsif menggunakan HTML, CSS, dan JavaScript tanpa framework.

## Menjalankan
1. Ekstrak file ZIP.
2. Buka `index.html` di browser (Chrome, Edge, Firefox, Safari).
3. Koneksi internet diperlukan untuk memuat gambar ilustrasi dari Unsplash.

## Sebelum dipublikasikan
- Verifikasi ejaan nama sekolah; kode menggunakan `SMP ISLAM SAWAHAN` sesuai permintaan.
- Ganti alamat, nomor telepon, email, peta, visi-misi, informasi program, berita, dan prestasi dengan data resmi.
- Ganti foto ilustrasi dengan dokumentasi sekolah yang diizinkan untuk dipublikasikan.
- Perbarui tautan email contoh.
- Form PPDB pada versi ini hanya melakukan validasi browser. Form tidak mengirim atau menyimpan data. Untuk pendaftaran nyata, buat backend/API dengan HTTPS, validasi server-side, perlindungan spam, kontrol akses, kebijakan privasi, dan penyimpanan yang aman.
- Periksa persetujuan publikasi foto dan data siswa.

## Hosting
Unggah `index.html` ke hosting statis (misalnya GitHub Pages, Netlify, atau layanan hosting sekolah). Jika menggunakan backend PPDB, deploy frontend dan backend sesuai panduan penyedia hosting dan ubah handler formulir agar mengirim data ke endpoint yang aman.

## Catatan
- Desain memakai HTML semantik, label formulir, fokus input, menu responsif, dan dukungan `prefers-reduced-motion`.
- Gambar eksternal merupakan ilustrasi, bukan klaim dokumentasi sekolah.
